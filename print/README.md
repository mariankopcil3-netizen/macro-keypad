# 3D print files

Print-ready files and settings for the physical keypad.

Expected content:

- `*.3mf` / `*.stl` — one file per part, oriented for printing
- `slicer-notes.md` — recommended settings per part (material, layer height,
  infill, supports, orientation)
- `bom.md` — bill of materials: screws, heat inserts, switches, encoder
  hardware, wiring
