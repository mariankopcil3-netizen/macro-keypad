# PCB design (KiCad)

KiCad project for the interface board that replaces the breadboard wiring:
ESP32 devkit socket or footprint, ST7789 FPC connector, keypad matrix header,
EC11 encoders and wiring to the key switches.

Expected content:

- `*.kicad_pro`, `*.kicad_sch`, `*.kicad_pcb` — KiCad 9 project files
- `gerbers/` — fabrication files (Gerbers, drill, pick&place)
- `bom.csv` / `pos-files` for ordering
