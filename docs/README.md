# Dokumentace

- `technicka-prirucka.md` — technická příručka: protokol, mapování kláves,
  build, Wokwi simulace, troubleshooting
- `images/` — screenshoty pro README
- `wiring/` — schémata zapojení (budou doplněna spolu s PCB)
- `demo.mp4` — ukázkové video (nahraj sem; README na něj odkazuje)

## Video v README

GitHub nevykresluje `<video>` tag v README, takže video se odkazuje
jako soubor: `docs/demo.mp4`. Až ho nahraješ, stačí v README odkaz
nebo GIF náhled (`docs/images/demo.gif`).

Alternativa bez velkého souboru v repu: nahrát video jako přílohu do
GitHub issue a vložit vygenerované `user-attachments` URL — GitHub ho pak
umí přehrát přímo v README.
