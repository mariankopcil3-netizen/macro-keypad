# PCB design (KiCad)

Interface deska, která nahradí zapojení na nepajivém poli: patice/footprint pro
ESP32 DevKit v1, FPC/hlavička pro ST7789 2.25", matice tlačítek, dva EC11
enkodéry a napájení.

## Plánovaný obsah

- `*.kicad_pro`, `*.kicad_sch`, `*.kicad_pcb` — KiCad 9 projekt
- `gerbers/` — výrobní soubory (Gerber, vrty, pick&place)
- `bom.csv` — nákladový seznam

Pin mapování je v [README.md](../README.md) a
[docs/technicka-prirucka.md](../docs/technicka-prirucka.md).
